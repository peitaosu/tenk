# TUI

默认界面：无子命令运行 `tenk`。CLI 子命令与 `--mcp` 不变。

## 布局

```
┌─ 自选 (~30%) ─┬─ 行情 / 详情 (~70%) ──────────────────────┐
│               ├─ K 线 ──────────────────────────────────────┤
├───────────────┴─────────────────────────────────────────────┤
│ 面板1 │ 面板2 │ … │ 面板N   （数量与类型由 -s 数据源决定）      │
└───────┴───────┴───┴──────────────────────────────────────────┘
{时间} · {代码} · {数据源} · {状态}          {快捷键提示}
```

底栏在**所有面板边框之外**（单行、全宽）。

Ratatui 约束：主区 `Length(h-1)` + 底栏 `Length(1)`；上 `Ratio(5,8)` / 下 `Ratio(3,8)`；上部分 `3:7`；右侧 `Max(7)` + `Min(4)`；底行按当前 feed 数量均分（`Ratio(1, N)`）。

## 面板

| 面板 | 数据 | 刷新 |
|------|------|------|
| 自选 | `get_market_current` | 每 3 秒轮询 |
| 行情 / 详情 | `get_market_current`、`get_valuation` | 切换标的、`r` |
| K 线 | `get_market` | 切换标的 / 周期 / 滚动；**图表**（chandelier）或**表格**（`v`） |

图表模式：`CandlestickChart` + `VolumeChart`（67% / 33%），红涨绿跌。表格模式：OHLCV 行。

底栏 feed 面板按数据源在 `tenk-cli/src/tui/feed.rs` 中定义。按标的的面板随标的切换刷新；全市场面板在启动时加载，聚焦时 `r` 刷新。

列表行：单行 **日期 · 元数据 · 标题**（元数据为来源、机构或「代码 名称」）。选中项全宽块高亮。TA / 分析师面板为摘要行。

## 数据源

TUI 仅使用**单一数据源**：默认东方财富，或通过 `-s` / `--source` 指定。不做多源回退。底栏面板数量与类型随数据源变化。

## 各数据源 feed 面板

| 数据源 | 面板（从左到右） |
|--------|------------------|
| 东方财富 (7) | 新闻 · 研报 · 市场 · 财经 · 美股 · 产经 · 机构调研 |
| 新浪 (5) | 新闻 · 研报 · 市场 · 美股 · 行业 |
| 同花顺 (3) | 新闻 · 研报 · 市场 |
| TradingView (5) | 新闻 · 市场 · 美股 · 技术分析 · 分析师 |

| 面板 | API | 范围 |
|------|-----|------|
| 新闻 | `search_news_for_symbol`（+ `search_news` 回退） | 标的 |
| 研报 | `get_research_reports` | 标的（各源 A 股 / 沪深北范围不同） |
| 市场 / 财经 / 美股 / 行业 … | `get_news(NewsCategory)` | 全市场 |
| 机构调研 | `get_institutional_research` | 全市场 |
| 技术分析 | `get_technical_analysis` | 标的 |
| 分析师 | `get_analyst` | 标的 |

新浪 / 同花顺标的新闻在 `search_news_for_symbol` 不可用时使用 `search_news` 关键词回退。

## 对话框

| 操作 | 内容 |
|------|------|
| 新闻类 feed `Enter` | `get_news_content` → 可滚动 `body_text` |
| 研报 feed `Enter` | 元数据（API 无全文） |

模态约占终端 80%；`Esc` 关闭。底栏显示对话框快捷键。

## 按键

| 键 | 作用 |
|----|------|
| `Tab` / `1–N` | 切换面板（`1` 自选、`2` 行情、`3` K 线、`4+` feed） |
| `j/k` | 滚动当前列表 |
| `Enter` | 选择标的 / 打开对话框 |
| `t` | 周期切换：单日 → 5日 → 日/周/月/5分…/60分 → 循环（K 线焦点） |
| `←/→` | K 线模式：分时 → 图表 → 表格（K 线焦点）；资讯面板翻页 |
| `v` | 同 `→` 切换 K 线模式（K 线焦点） |
| `j/k` | 滚动 K 线窗口（K 线焦点） |
| `/` | 搜索股票（Enter 添加到自选） |
| `d` | 删除当前自选（自选面板） |
| `r` | 刷新当前面板 |
| `:` | 命令行（`add`、`remove`、`refresh`、`quit`） |
| `?` | 帮助 |
| `Esc` | 关闭对话框 / 命令行 |
| `q` | 退出 |

## 配置

`~/.config/tenk/watchlist.txt` — 每行 `CODE:EXCHANGE` 或 `code\tEXCHANGE[\t名称]`。默认：`600519:SH`、`000001:SZ`、`510300:SH`。

## 参数

与 CLI 相同的全局选项：`--lang`、`--proxy`、`-s` / `--source`。

## 实现

`tenk-cli/src/tui/` — `app`、`feed`、`fetch`、`render`、`kline`、`dialog`、`config`、`style`。K 线图表：[chandelier](https://docs.rs/chandelier)。
